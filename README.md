# AI Career Copilot 🚀

AI-powered career assistant for resume analysis, job matching and AI resume generation.

## Features

- Resume PDF Upload
- AI Resume Analysis
- Resume Score
- Job Description Matching
- AI Resume Builder
- Resume PDF Export
- JWT Authentication
- MongoDB Database

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

### AI
- Google Gemini API
